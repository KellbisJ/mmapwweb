# MMapWWeb - Simple Mind Map Web Application

A lightweight, browser-based mind mapping tool designed for brainstorming and organizing ideas. Built with a focus on simplicity, security, and ease of use.

![MmapWweb Screenshot](https://ik.imagekit.io/137/MmapWweb/mmap%20readme%20baaner.png)

## Inspiration & Story

MMapWWeb was born out of boredom during university studies! I needed a tool to generate an initial idea for my mind map assignment. I decided I wanted something simple that let me focus on _my_ ideas and I created this simple mind map web project.
